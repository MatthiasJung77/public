# Prompts

Prompts und Prompt-Vorlagen, die ich in der Praxis nutze.

## Ablage

- Eine Datei pro Prompt, als Markdown: `prompts/<thema>/<kurzer-name>.md`
- Themenordner nach Bedarf anlegen, zum Beispiel `schreiben/`, `recherche/`, `datenbanken/`
- Als Ausgangspunkt dient [`_vorlage.md`](_vorlage.md)
