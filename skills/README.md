# Skills

Skills für Claude und andere Agenten. Ein Skill bündelt Anweisungen und bei Bedarf Hilfsdateien für eine wiederkehrende Aufgabe.

## Ablage

- Ein Ordner pro Skill: `skills/<skill-name>/`
- Pflichtdatei ist `SKILL.md` mit Frontmatter (`name`, `description`)
- Optionale Hilfsdateien (Skripte, Vorlagen, Beispiele) liegen im selben Ordner
- Vor der Veröffentlichung prüfen: keine internen Pfade, Kundennamen, Zugangsdaten oder persönlichen Daten

```text
skills/
  beispiel-skill/
    SKILL.md
    vorlagen/
```
