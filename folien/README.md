# Folien

Folien aus Vorträgen, Webinaren und Workshops.

## Ablage

- Ein Ordner pro Vortrag: `folien/<jahr>/<jahr-monat>-<anlass>-<kurztitel>/`
- Darin die Folien als PDF und eine kurze `README.md` mit Titel, Anlass, Datum und Abstract
- Große Quelldateien (PPTX, Keynote) nur ablegen, wenn sie wirklich gebraucht werden

```text
folien/
  2026/
    2026-11-doag-beispieltitel/
      README.md
      folien.pdf
```
